# Contributing

Contributions that improve documentation, accessibility, validation, and maintainability are welcome.

1. Open an issue explaining the proposed change.
2. Create a feature branch from `master`.
3. Keep changes focused; do not alter existing login or registration behavior without tests.
4. Use the .NET 8 SDK. Run `dotnet restore` and `dotnet build LoginSignup.sln` before proposing changes.
5. Never commit real credentials, personal records, or machine-specific settings.

Include a short testing summary in your pull request.
